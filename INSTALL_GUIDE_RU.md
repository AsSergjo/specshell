# Установка и удаление

[English README](README.md)

## Перед установкой

Программа не содержит FFmpeg. Установите FFmpeg и добавьте каталог с
`ffmpeg.exe` и `ffprobe.exe` в переменную `PATH`.

Откройте новую CMD-консоль и проверьте:

```bat
where ffmpeg.exe
where ffprobe.exe
```

Если пути не отображаются, установка программы не будет выполнена.

## Установка

1. Запустите `SpectrogramContextMenu.exe` двойным щелчком.
2. Дождитесь сообщения об успешной установке.
3. Нажмите правой кнопкой мыши на аудиофайле.
4. Выберите «Показать спектрограмму».

Права администратора не нужны. Программа устанавливается только для текущего
пользователя в `%LocalAppData%\Programs\SpectrogramContextMenu`.

В Windows 11 команда может находиться в разделе «Показать дополнительные
параметры». Перезапускать `explorer.exe` вручную не требуется.

## Обновление и восстановление

Для обновления запустите новую версию `SpectrogramContextMenu.exe` обычным
двойным щелчком. Для восстановления регистрации используйте:

```bat
SpectrogramContextMenu.exe /repair
```

## Удаление

Удалить программу можно в разделе Windows «Установленные приложения» либо
командой:

```bat
"%LocalAppData%\Programs\SpectrogramContextMenu\SpectrogramContextMenu.exe" /uninstall
```

Удаляются контекстное меню, запись установленного приложения и установленный
EXЕ. FFmpeg не изменяется.
